# Running

If you have a Game tab, change it to Simulator.

<img
    alt="Screenshot of Simulator selection"
    src="assets/select-simulator.png">

Then choose a standard phone size device to simulate, such as iOS Notch Device (1170x2532).

<img
    alt="Screenshot of device selection"
    src="assets/select-device.png">

You can then use the Play button to start the app.

<img
    alt="Screenshot of play and pause controls"
    src="assets/play-pause-controls.png">
